# 🍔 Vintage Food — доставка бургеров

Лендинг службы доставки: hero-блок с акцией, каталог категорий меню и футер с контактами.

**🔗 Демо:** https://uzakilaa.github.io/vintage-food/

![Скриншот](images/hero-burger.png)

## Стек
- HTML5
- CSS3: Flexbox, CSS Grid (`auto-fit` / `minmax`), градиенты, медиазапросы
- Google Fonts (Montserrat)

## Что реализовано
- Резиновая сетка каталога, которая сама перестраивается под ширину экрана
- Адаптив от десктопа до телефона
- Hover-анимации карточек и кнопок

## Запуск
Скачайте репозиторий и откройте `index.html` в браузере.
